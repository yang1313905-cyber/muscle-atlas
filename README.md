# 肌图志 · Muscle Atlas

交互式全身人体肌肉解剖与健身动作速查网页版（数据层与矢量路径层完全解耦，零后端运维，可随时扩展《超级套表》训练计划模块或移植至微信小程序）。

## 核心能力

- **双精细度一键切换**：
  - **小白精简模式（14 大部位）**：直观点击整块大肌群，零门槛速查。
  - **专业细分模式（37 块细分肌群/肌束）**：细分至胸大肌上/中/下束、三角肌前/中/后束、斜方肌上/中/下束、肱三头肌三头、股四三表层头、腘绳肌内外侧、腓肠肌/比目鱼肌等，规避完整三角肌误亮问题。
- **双层动作展示**：点击任意肌肉，同时呈现「**最适合的锻炼动作（主攻推荐）**」与「**会涉及到这块肌肉的所有健身动作（主攻 / 协同 / 稳定）**」，支持按器械与复合/孤立筛选。
- **双向动作热力图**：点击任意动作「体图热力预览」，按精准参与肌束在正背面人体图上高亮主攻、协同与稳定肌。
- **标准解剖关节功能 + 练后拉伸**：整合校对后的《推拿按摩的解剖学基础》附录 16 大关节 / 75 组关节活动（区分主动运动与核心等长对抗）与 29 个全身练后拉伸动作（含初/中/高级组数时长）。

## 本地运行与测试

```bash
npm install
npm run dev       # 本地开发预览（默认 http://localhost:5173）
npm test          # 运行 37 项核心数据、解剖守卫与 SVG 覆盖测试
npm run typecheck # TypeScript 严格类型检查
npm run build     # 生成可部署至 Vercel / Cloudflare Pages 的静态产物 dist/
```

## 目录架构（为小程序移植与新模块预留）

- `src/core/` — 纯 TypeScript 知识库与查询引擎（零 DOM/React 依赖，未来可直接复用于微信小程序）
- `src/anatomy/svgPaths.ts` — 统一坐标系（`360×720`）正背面肌肉矢量路径（Web 端用于 SVG，小程序端可直接喂给 Canvas `Path2D`）
- `src/components/` — 响应式 Web 界面（支持深浅双主题与手机/桌面端自适应）
- `src/core/types.ts` — 已预留 `WorkoutPlanTemplate` 接口，后续直接接入你的《超级套表》训练计划模块
